# Project Structure

```
src/
├── Api/                                    ← ASP.NET Core Web API entry point
│   ├── Controllers/                        ← [ApiController] classes (HTTP dispatch only)
│   ├── Middleware/                         ← Exception handler, request logging
│   ├── Program.cs                          ← App bootstrap + DI registration
│   └── appsettings.json                    ← Base configuration
│
├── Application/                            ← Use cases, interfaces, DTOs
│   ├── Features/                           ← One folder per domain feature
│   │   └── <Feature>/
│   │       ├── Commands/                   ← MediatR IRequest<T> command + handler
│   │       ├── Queries/                    ← MediatR IRequest<T> query + handler
│   │       └── DTOs/                       ← Request/response records for this feature
│   └── Common/
│       ├── Interfaces/                     ← Repository and service contracts (IRepository<T>)
│       ├── Exceptions/                     ← NotFoundException, ValidationException, etc.
│       └── Behaviours/                     ← MediatR pipeline behaviours (validation, logging)
│
├── Domain/                                 ← Entities, value objects, domain events
│   ├── Entities/                           ← Aggregate roots and child entities
│   ├── Common/                             ← BaseEntity, IDomainEvent, ValueObject base
│   └── Enums/                              ← Domain enumerations
│
└── Infrastructure/                         ← EF Core, external services, persistence
    ├── Persistence/
    │   ├── ApplicationDbContext.cs
    │   ├── Configurations/                 ← IEntityTypeConfiguration<T> per entity
    │   ├── Migrations/                     ← EF generated migration files
    │   └── Repositories/                   ← IRepository<T> implementations
    └── Services/                           ← External service implementations

tests/
├── Application.UnitTests/                  ← MediatR handler unit tests (NSubstitute mocks)
└── Api.IntegrationTests/                   ← WebApplicationFactory + Testcontainers tests

requirements/                               ← Feature requirement docs (generated by /plan-feature)
docs/                                       ← Generated documentation (generated by /document)
```

## Rules

- Controllers must not contain business logic — call `_mediator.Send()` and return the result
- Command/query handlers are the only place for business logic — no logic in controllers or repositories
- Domain entities must not reference Application or Infrastructure types
- All repository contracts live in `Application/Common/Interfaces/` — implementations in `Infrastructure`
- DTOs/response records live in `Application/Features/<Feature>/DTOs/` — never return Domain entities from controllers
- `ApplicationDbContext` lives only in `Infrastructure` — never referenced in Application or Domain
- EF migrations: `dotnet ef migrations add <Name> --project Infrastructure --startup-project Api`
