# Project Structure

```
app/                      ← Expo Router file-based routes (screens only, no business logic)
├── _layout.tsx           ← Root layout (navigation container, global providers)
├── index.tsx             ← Home / entry screen
├── (auth)/               ← Auth group: login, register screens
│   └── _layout.tsx
└── (app)/                ← Protected group: main app screens
    └── _layout.tsx

src/
├── components/           ← Reusable UI components (no business logic)
├── hooks/                ← Custom hooks only (useXxx.ts)
├── services/             ← All API calls + data fetching logic
├── context/              ← React Context providers
├── lib/                  ← Pure utility functions (no React / RN imports)
├── types/                ← TypeScript interfaces, types, enums
└── constants/            ← App-wide constants (colors, sizes, config keys)

assets/                   ← Images, fonts, icons
requirements/             ← Feature requirement docs (generated by /plan-feature)
docs/                     ← Generated documentation (generated by /document)
```

## Rules

- `app/` screens import from `src/components/`, `src/hooks/`, `src/services/` — never the reverse
- `src/services/` must not import from `src/components/` or `app/`
- `src/lib/` must have zero React / React Native imports
- Test files live next to the file they test: `Button.tsx` → `Button.test.tsx`
- One component per file — no barrel files that re-export many components
